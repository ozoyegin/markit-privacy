Markit Highlighter

User Guide for the Chrome extension — save words and phrases from web pages and PDFs, listen to them, and practise them in Markit.

Markit Highlighter helps you collect language from what you are reading. Your lists, records, progress and preferences are stored locally in your Chrome profile.

Quick start: create a list in the Markit popup, choose it in Save to, select text on a page or PDF, then use Add to Markit.

2. Create lists and save records

Use the extension popup to create a named list. A list can have its own highlight colour, language and browser voice. You can also create sublists to keep subjects or courses organised.

  • Use Save to to select the active list before reading.
  • Use the list editor to change a record’s selection, translation or example sentence.
  • Use a list’s actions to create a sublist, move records or copy records to another list.
  • Search finds text in saved selections, translations and example sentences.

Saved words and phrases are highlighted automatically on supported pages. The extension badge shows the match count for the current page.

3. Save text from web pages

  1. Select a word, phrase or sentence on a web page.
  2. Use the small Add to Markit control that appears near the selection.
  3. Review the selection, add an optional translation, then save it to the active list.

You can also right-click selected text and choose Add to Markit from Chrome’s context menu. This is useful on pages where an in-page control is unavailable.

4. Read and save from PDFs

Open a PDF with the Markit PDF Reader. Select text to show a compact card with the selected-text preview, a speaker button, repeat and speed settings, and Add selection.

  • Speed: choose from x0.25 through x2.
  • Repeat: repeat an item from 1 to 9 times.
  • Saved records: hover a highlighted saved record to listen, edit it, or adjust its repeat and speed.
  • PDF voice settings: use the gear icon in Saved records to choose a reading language, voice and test the voice.
  • Study time: time spent while PDF speech is playing is added to your daily study-time total. Voice tests are not counted.
Local PDFs: in chrome://extensions, open Markit’s Details page and enable Allow access to file URLs.

5. Study and Game Practice

Open a list and choose a study option. Learn and Review follow the same learning model as the Markit Android app.

ModePurpose
LearnWorks through Level 0 and Level 1 records. Completing the session successfully raises a record by one level.
ReviewShows records whose review time is due, including mastered records.
MatchMatch words with their meanings.
GuessChoose the correct meaning from four choices.
FlashcardsReveal the card and check yourself.
WriteType the word from its translation. French and English word suggestions can appear while typing.

In Game Practice, records are shown in their creation order and Markit remembers the current position separately for each game mode and list. Learn and Review use their own prioritised scheduling and are not changed by this.

Keyboard shortcuts: use Enter to Show, Check, Next, Continue or Close when the relevant action is available. In choice games, use arrow keys to move between answers.

6. Progress

The Progress screen shows study time, answer results, learning levels and list progress. Listening in the PDF Reader contributes to total study time only; it does not change a record’s level, correct/wrong counts or practice results.

7. Backup, restore and transfer

  • Backup / Restore: saves or restores the whole extension data set as a JSON backup. This includes lists, sublists, records, study data, analytics, compatible preferences and saved Game Practice positions.
  • Export / Import: use XLSX for spreadsheet-oriented transfers. Markit-generated XLSX files preserve Markit metadata.
  • Export this list / Import list: use .markitlist to transfer one list with the Markit Android app. It includes direct records, translations, sentences and learning progress. For a complete nested hierarchy, use Backup instead.
Back up before replacing, restoring or moving data to another Chrome profile or computer. A backup is the safest way to preserve all lists and progress together.

8. Privacy and storage

Markit Highlighter stores its data in Chrome’s local extension storage. It does not require a server or Raspberry Pi. Your saved lists, records and study data remain in the local Chrome profile unless you export or back them up yourself.

The extension needs page access to find and highlight saved text. Browser-internal pages, the Chrome Web Store and some protected pages do not permit extensions to inject page controls.

9. Troubleshooting

Highlights or controls do not appear

Refresh the page, confirm the relevant list is enabled, and check that the page is not a Chrome-internal or protected page. Use Apply to tab from the popup if needed.

A local PDF does not load

Enable Allow access to file URLs in the extension’s Chrome Details page, then reopen the PDF.

A voice is unavailable on another computer

Voice names are provided by the operating system and browser. Markit keeps the list language and falls back safely to an available default voice.

Data needs to be moved or recovered

Use Backup from the original Chrome profile, then Restore it in the destination profile. Keep the backup file until you have verified the restored lists.
